# 🛒 Flutter E-Commerce App with Admin Panel

A Flutter E-Commerce Application built using Flutter, Dart, Firebase, BLoC state management, and Stripe Payment Gateway integration. The app includes a user shopping experience and a dedicated admin panel for managing products, categories, and orders.

## ✨ Features

### 👤 User App
- User Authentication with Firebase
- Browse Products and Categories
- Search and View Product Details
- Product Sizes, Colors, and Prices
- Shopping Cart and Quantity Management
- Place Orders and View Order History
- Stripe Payment Gateway Integration

### 🛠️ Admin Panel
- Admin Dashboard
- Add, Update, and Delete Products
- Manage Product Categories
- View All Customer Orders
- View Customer Information
- Update Order Status

## 🧰 Technologies Used
- **Flutter** — Cross-platform UI Development
- **Dart** — Programming Language
- **Firebase Authentication** — User Authentication
- **Cloud Firestore** — Database Management
- **BLoC** — State Management
- **Stripe** — Payment Gateway Integration
- **Git & GitHub** — Version Control

## 🏗️ Architecture

The application follows BLoC architecture to separate business logic from the UI, making the code organized, maintainable, and scalable.

## 🚀 Getting Started

1. Clone this repository.
2. Open the project in VS Code or Android Studio.
3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Configure Firebase for your application.
5. Configure Stripe using a secure backend.
6. Run the application:

   ```bash
   flutter run
   ```

## 🔐 Security

Never upload Stripe secret keys or other sensitive credentials to GitHub. Use a secure backend to create PaymentIntents and verify payments before deploying the application to production.
